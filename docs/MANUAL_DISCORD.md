# Ручные касания в Discord — чеклист LocForge

Когда бота нет на сервере (Godot/Unity и т.п.) — отправляете **сами**, шаблоны берёте из плана.

Связанные файлы:
- план дня: `plans/day-01-2026-08-10.md`
- доступные боту каналы: `plans/day-discord-accessible.md`
- учёт: `data/outreach-leads.csv`
- конфиг: `data/config.json`
- генерация текста без отправки: `python run_test.py`

---

## Workflow: скинуть URL агенту

1. Зайдите в канал Discord своим аккаунтом.
2. Скопируйте URL из адресной строки браузера/клиента:  
   `https://discord.com/channels/GUILD_ID/CHANNEL_ID`  
   (можно и URL конкретного сообщения).
3. Пришлите ссылку в чат Cursor — агент прогонит `scout.py`.
4. В ответе будут:
   - найденные посты с сигналами
   - готовые черновики (DM или Reply)
5. Отправьте выбранный draft вручную → отметьте в `data/outreach-leads.csv`.

Локально без чата:
```powershell
python scout.py "https://discord.com/channels/GUILD/CHANNEL" --limit 5
```

---

## 0. Подготовка

1. Откройте план касаний и CSV.
2. В Discord включите Developer Mode: **Settings → Advanced → Developer Mode**.
3. Держите под рукой ссылку пилота:
   - EN: `https://gameforge.website/en/locforge?...`
   - RU: `https://gameforge.website/ru/locforge?...`

---

## 1. Найти живой пост

1. Зайдите на сервер **своим обычным аккаунтом**.
2. Откройте целевой канал (#showcase, #game-dev, announce и т.п.).
3. Ищите пост с сигналом:
   - localization / translate / перевод / CSV
   - Steam / EN-only / multilingual
   - релиз / showcase инди-игры
4. **Не пишите вхолодную** без повода — только при публичном intent.

---

## 2. Собрать текст

1. Скопируйте шаблон из плана (`dm_en` / `comment_en` / `dm_ru`).
2. Замените `{game}` или `{игру / пост}` на название из поста.
3. Проверьте, что в тексте есть:
   - free pilot / бесплатный пилот
   - ссылка на LocForge
   - упоминание CSV
4. Опционально сгенерируйте текст агентом (без реальной отправки):

```powershell
python run_test.py
```

Возьмите готовое сообщение из консоли / `logs/test_report_*.txt`.

---

## 3A. Шаблон `comment_*` — публичный ответ

1. Под постом нажмите **Reply**.
2. Вставьте текст.
3. Отправьте один раз.
4. Не дублируйте одному человеку в нескольких тредах за день.

---

## 3B. Шаблон `dm_*` — личные сообщения

1. ПКМ по автору → **Message**.
2. Если ЛС закрыты — публичный reply или **пропуск**.
3. Вставьте персонализированный текст и отправьте **одно** сообщение.
4. Follow-up — максимум через **5 дней**, если нет ответа.

---

## 4. Отметить в учёте

В `data/outreach-leads.csv` для нужного `id`:

| Поле | Значение |
|------|----------|
| `status` | `sent` |
| `sent_at` | дата, например `2026-08-11` |
| `author` | ник Discord |
| `game_name` | название игры |
| `notes` | ссылка на пост / короткий комментарий |

В markdown-плане поставьте `- [x] Sent`.

---

## 5. Если ответили

В CSV:

| Поле | Значение |
|------|----------|
| `reply` | `yes` / `no` / `maybe` |
| `reply_at` | дата/время |

Дальше пилот: попросить CSV `key,source` на  
`gameforge.website@yandex.ru` (subject: `LocForge pilot`).

## Мини-чеклист на день (10 касаний)

- [ ] 1–2 Discord авто (если каналы доступны боту):  
      `python run_outreach.py --plan day-discord-accessible.md --limit 2`
- [ ] Остальные Discord — вручную по шагам выше
- [ ] Reddit / TG / VK — вручную по шаблонам из `plans/day-01-2026-08-10.md`
- [ ] CSV обновлён
- [ ] В плане отмечены Sent
- [ ] Ответы занесены в `reply`

---

## Частые ошибки

- Спам в официальные каналы без intent → бан / игнор
- Забыли подставить название игры
- Нет ссылки или CSV в тексте
- Повторный DM тому же человеку раньше 7 дней
- Не обновили CSV — теряется конверсия
