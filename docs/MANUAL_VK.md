# Ручные касания в VK — чеклист LocForge

Когда `vk_token` в `data/config.json` пуст — скаут и отправка **вручную** через браузер (как Reddit).

Связанные файлы:
- план дня: `plans/day-01-2026-08-10.md` (касание id=15)
- отчёты скаута: `logs/scout_vk_*.md`
- учёт: `data/outreach-leads.csv`
- конфиг: `data/config.json`

---

## Workflow

1. Скаутить целевые сообщества (CIS-режим Day7+):
   - https://vk.ru/krri.gamedev — Русские инди / КРРИ (**приоритет**)
   - https://vk.ru/gamedev56 — Разработка игр / Инди игры
   - при необходимости: Last Indie Standing (только посты автора-разработчика)
   - https://vk.ru/play_with_ducat — **blacklist** (не питчить)
2. Сигналы: Steam-страница, вишлист, локализация/перевод, CSV, EN-first, демо/релиз.
3. Черновики → `logs/scout_vk_*.md`
4. Один публичный **comment** (предпочтительно) или DM → отметить в CSV.

---

## 1. Найти живой пост

Ищите **публичный intent**:
- «страница в Steam» / вишлист / трейлер
- вопрос про локализацию / перевод / CSV
- WIP с явным запросом фидбека

Не пишите вхолодную под чужой обзорный репост без автора-разработчика.

---

## 2. Comment (предпочтительно)

1. Откройте пост своим аккаунтом.
2. «Написать комментарий…» → draft из scout report.
3. Подставьте реальное название игры.
4. **1 касание / день** по day-плану; не копируйте один текст в 5 пабликов подряд.

UTM: `utm_source=vk&utm_medium=comment&utm_campaign=lf_ru`

**Автоматизация (Playwright):** не используйте `keyboard.type()` для текста с переносами строк. В VK `\n` = **Enter** = отправка комментария → получаются дубликаты (частичные + полный). Вставляйте целиком через clipboard/`insertText`, затем один клик «Отправить». Перед отправкой проверьте, что в треде ещё нет вашего текста.


---

## 3. DM (осторожно)

1. Только после ответа на comment или если OP явно просит help/loc/CSV.
2. Холодные ЛС новым аккаунтам VK часто режет / помечает как спам.
3. UTM: `utm_medium=dm`.

Шаблон `dm_ru` (из плана):

```
Привет! Увидел {игру / пост}. LocForge — локализация инди CSV за один вечер: глоссарий, QA длины UI, экспорт Unity/Godot.

Могу сделать бесплатный пилот (RU/ES/DE) — особенно удобно, если сейчас EN-сборка, а RU/ES/DE нужны до Steam. Если ок — укажем игру в кейсе на лендинге.

https://gameforge.website/ru/locforge?utm_source=vk&utm_medium=dm&utm_campaign=lf_ru&from=locforge
Или просто пришлите CSV в ответ.
```

---

## 4. Антиспам

- CIS-режим: до **3 VK-касаний / день** (разные посты/паблики, ≥10 мин, разный угол). Иначе по умолчанию **1 / день**.
- Не автоматизируйте пачку комментариев через браузер подряд (риск блокировки, как на Reddit).
- Cooldown **7 дней** на одного автора.
- Не питчите в сообществах переводчиков-конкурентов (напр. masterkosta).

## 5. Учёт в CSV

- `status=sent` после отправки
- `sent_at=YYYY-MM-DD`
- `author`, `game_name`, `notes` с URL поста/комментария
