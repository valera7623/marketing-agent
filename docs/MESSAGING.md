# LocForge — тон и шаблоны сообщений

Обновлено после реакции в `@gamedev_chat_rus` (авг 2026): повторяющиеся value-post'ы про «CSV + глоссарий» воспринимаются как спам; аудитория знает Unity Localization / I2 / Godot Localization.

---

## Позиционирование (что говорим)

**LocForge — не замена Unity Localization / Godot Localization.**

| Пакет движка уже делает | LocForge добивает |
|-------------------------|-------------------|
| сбор строк, ключи, импорт/экспорт | **согласованность терминов** (глоссарий между файлами) |
| plural / locale | **length QA** (DE/RU ломают кнопки, HUD) |
| одна таблица в проекте | **сверка** achievements ↔ in-game, store ↔ билд, recipe book ↔ HUD |
| — | QA **без бюро**, на sample CSV |

**Одна боль на сообщение** — не перечислять весь список возможностей.

## Банк углов (ротация — не повторять подряд в одном чате)

| Угол | Когда | Пример фразы |
|------|-------|----------------|
| Length QA | UI-heavy, VN, card game | «DE на 40% длиннее — кнопка „Equip“ не влезает» |
| Glossary drift | RPG, skills, lore | «Fireball / Огненный шар / Flame в трёх файлах» |
| Achievements | Steam page live | «achievement в Steam ≠ строка в билде» |
| Recipe / glossary UI | card/craft games | «название в книге рецептов ≠ на карте в HUD» |
| CSV merge | team / Godot | «после merge в Git пропали ключи — импорт молчит» |
| Post-patch sync | RU+EN уже есть | «после патча субтитры и HUD разъехались» |
| Store ↔ build | multilang Steam | «описание в store и tooltip в игре — разные слова» |

**Не использовать** как самостоятельный пост: «ключи + глоссарий + length QA» без привязки к игре.
